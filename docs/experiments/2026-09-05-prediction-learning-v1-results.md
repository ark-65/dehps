# DEHPS 首轮预测学习结果：证据不足

Goal：`dehps-prediction-learning-v1`。这是已完成训练、评估及 replay 的第一轮历史探索性实验，不是新独立验证集，不替换 Formal P3。

收缩模型相对旧模型降低了样本外红球 log-loss，但没有证明优于合法均匀边际基线。分散选票提高了平均最大红球命中数，收益对照的配对区间仍跨 0。不能把这两类变化合并称为已获得预测优势。

## 模型、数据与固定规则

- 数据：2003001–2026102，共 3,499 期完整红球和蓝球标签；来源 zhcw，只读快照通过日期、期号唯一性、年内连续性和合法号码检查。
- 前 900 期是原冻结模型要求的训练起点。它们保留完整标签并标记 `INSUFFICIENT_PRIOR_HISTORY`，不伪造原模型预测。之后 2,599 期逐期严格使用此前历史，评估期为 2009076–2026102。
- 所有历史均为已用于研究的数据。旧模型历史输出按冻结规则重建，不冒充原始开奖前 artifact；可用性假设是历史开奖日期，非原始入库时间。
- 主模型预先固定为 expanding shrink900：`q_i=(c_i+900×6/33)/(n+900)`。其它配置是 expanding alpha=100、156 期窗口 alpha=100、半衰期156期 alpha=100。固定对照是原 alpha=1 模型和均匀 q=6/33。
- 共 4 个可调配置，无外层结果选模，无概率校准拟合，无新增非线性候选。各红球概率向量和为6。组合评分只是边际 Bernoulli 的复合 log2 分数，未学习联合结构。
- 蓝球保留完整标签，使用原始按票序确定的共享均匀蓝球策略。每个随机对照每期32组、每组100注；完整随机蓝球单独比较。
- 全部配置、seed=20260905、时间切分、4,000次长度13的循环区块 bootstrap、八项主指标对照的 Bonferroni 方法，均在首次评估之前冻结。

实验合同：`8e9ec9f83dc7da1587389ec7952c2ff037514daf5400dc8546b4a5bc1e04a033`。
数据快照：`8d0529e3ca628942f6162bff5917d5aaba91ffe1450cb7a271a529e384ceacd6`。
